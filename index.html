JUST ENOUGH CODE TO BE DANGEROUS

Nobody Creative started during a job search, when a marketer with some basic coding skills needed somewhere to put the ideas that didn’t belong in a cover letter.

So I started building them. Tiny games. Useful tools. Weird experiments. Some are polished products; some are prototypes with excellent intentions. The point is to stay curious, sharpen the creative muscles, and turn strategy into things people can actually click, play, or use.

This site is the messy lab. My portfolio is the cleaned-up case file.
